## Question
Using the gnomAD v2.1.1 genomes data for chromosome 17, determine the smallest start position and largest end position of any variant whose nested VEP annotations contain the symbol 'BRCA1'. Then, for all variants whose positions fall within that gene region, retrieve the 'Protein_position' values only if the 'Consequence' includes 'missense_variant', sort them in ascending order by 'Protein_position', and finally output the first such result.

## Attempt 1
```sql
WITH region AS (
  SELECT MIN(t.start_position) AS min_start, MAX(t.end_position) AS max_end
  FROM `bigquery-public-data.gnomAD.v2_1_1_genomes__chr17` AS t,
    UNNEST(t.alternate_bases) AS ab,
    UNNEST(ab.vep) AS v
  WHERE v.SYMBOL = 'BRCA1'
)
SELECT v.Protein_position
FROM `bigquery-public-data.gnomAD.v2_1_1_genomes__chr17` AS t,
  UNNEST(t.alternate_bases) AS ab,
  UNNEST(ab.vep) AS v,
  region AS r
WHERE t.start_position >= r.min_start
  AND t.end_position <= r.max_end
  AND v.Consequence LIKE '%missense_variant%'
  AND v.Protein_position IS NOT NULL
  AND v.Protein_position != ''
ORDER BY v.Protein_position ASC
LIMIT 1
```
