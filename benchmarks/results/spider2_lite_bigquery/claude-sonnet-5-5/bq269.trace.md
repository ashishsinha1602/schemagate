## Question
Between June 1, 2017, and July 31, 2017, consider only sessions that have non-null pageviews. Classify each session as ‘purchase’ if it has at least one transaction, or ‘non_purchase’ otherwise. For each month, sum each visitor’s total pageviews under each classification, then compute the average pageviews per visitor for both purchase and non-purchase groups in each month, and present the results side by side.


## Tables selected by schemagate (1 of 1)

Prompt schema fragment: 9835 characters.

## Attempt 1
```sql
WITH s AS (
  SELECT
    SUBSTR(date, 1, 6) AS month,
    fullVisitorId,
    IF(IFNULL(totals.transactions, 0) >= 1, 'purchase', 'non_purchase') AS cls,
    totals.pageviews AS pageviews
  FROM `bigquery-public-data.google_analytics_sample.ga_sessions_*`
  WHERE _TABLE_SUFFIX BETWEEN '20170601' AND '20170731'
    AND totals.pageviews IS NOT NULL
),
v AS (
  SELECT month, cls, fullVisitorId, SUM(pageviews) AS total_pv
  FROM s
  GROUP BY month, cls, fullVisitorId
)
SELECT
  month,
  SAFE_DIVIDE(SUM(IF(cls = 'purchase', total_pv, 0)), COUNT(DISTINCT IF(cls = 'purchase', fullVisitorId, NULL))) AS avg_pageviews_purchase,
  SAFE_DIVIDE(SUM(IF(cls = 'non_purchase', total_pv, 0)), COUNT(DISTINCT IF(cls = 'non_purchase', fullVisitorId, NULL))) AS avg_pageviews_non_purchase
FROM v
GROUP BY month
ORDER BY month
```
