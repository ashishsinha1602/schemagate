# The schemagate name

The **code** in this repository is Apache-2.0. Take it, fork it, sell what you
build with it — that is what the licence is for, and nothing below narrows it.

The **name** is separate. Section 6 of the Apache Licence grants no rights to
a project's trade names or trademarks, and this file says what that means in
practice, so nobody has to guess.

"schemagate" and the schemagate logo are trademarks of Ashish Sinha.

## You do not need to ask

- Saying your software uses, supports, integrates with, or is compatible with
  schemagate. Describing what a thing does is not trademark use.
- `pip install schemagate`, importing it, depending on it, packaging it for a
  distribution under its own name.
- Writing about it: tutorials, comparisons, benchmarks, criticism, a talk, a
  paper. Publishing a benchmark that makes schemagate look bad is explicitly
  fine — this project publishes its own corrections and expects the same
  freedom for everyone else.
- Unmodified redistribution of a release, keeping the name.

## Please ask first

- Naming your own product, service, or company something containing
  "schemagate" — "schemagate Pro", "schemagate Cloud", "Schemagate Inc".
- A hosted or commercial service presented *as* schemagate rather than as
  your own product built on it.
- Using the logo as your own, or in a way that suggests this project endorses
  or maintains what you are shipping.

## Please do not

- Ship a **modified** version under the schemagate name. Fork it and call it
  something else — that is the one that matters, because a user who hits a
  bug in your fork will file it here and be told a number this project never
  measured. The benchmarks in this repository are claims about *this* code.
- Register "schemagate", or a name likely to be confused with it, as a
  trademark, domain, package name, or social handle.
- Imply endorsement, partnership, or certification that does not exist.

## Why this file exists at all

The measurements in `BENCHMARKS.md` are the point of this project, including
the ones that were wrong and got corrected in public. That is only worth
anything if "schemagate says 80.6%" refers to a specific thing somebody can
check. A fork shipping different retrieval under the same name makes every
number in this repository unfalsifiable, which costs the reader more than it
costs me.
